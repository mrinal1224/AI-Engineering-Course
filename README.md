# AI Engineering with JavaScript

A first-principles, production-oriented AI Engineering curriculum for JavaScript developers.

## Course Philosophy

This course is designed around one rule:

> **Understand the abstraction before using the abstraction.**

Students will first understand and implement the core ideas behind LLM applications, then use production frameworks and managed services.

## Stack

- JavaScript / Node.js
- TypeScript where useful
- Express
- React
- OpenAI / Gemini APIs
- MongoDB
- Chroma / other vector databases
- LangGraph
- MCP
- Ollama
